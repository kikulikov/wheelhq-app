About WheelHQ

Covered call and cash-secured put screener for S&P 500 and Nasdaq-100 stocks. Runs in your browser. No account, no profile.

What WheelHQ does

WheelHQ screens cash-secured puts and covered calls across the S&P 500 and Nasdaq-100. Filter by sector, yield, annualized return, delta, DTE, spread and price bucket; the table updates in your browser. Earnings and ex-dividend dates before expiry are marked in the expiry column.

How the screen works

WheelHQ reads market data from Alpaca. It asks for stock snapshots for the selected universe, orders candidates by last completed session dollar volume, and fetches option chains for the expiry and strike window you choose. Delta and the other filters are applied in the browser, so ordinary screening does not send every filter change back to the data provider.

Free Alpaca keys use the delayed indicative feed; real-time OPRA data needs an options data subscription. A scan can stop early when Alpaca’s rate limit is reached, and custom lists screen their own names.

Your Alpaca key

WheelHQ has no market-data service or account of its own. You connect your own Alpaca API key so the browser can read option chains and stock prices directly from Alpaca. The key is stored in this browser: session-only by default, or in local storage only when you tick Keep this key on this device. It is sent only to *.alpaca.markets and is never sent to WheelHQ. You can remove it at any time from Data and API status.

Prefer a paper-trading key. A live key can place trades if it leaks. A market-data-only key is enough for screening; options data access decides whether quotes are delayed or real-time. WheelHQ never places trades.

No account, no profile

There is no sign-up, no profile page and no user database. WheelHQ is a static site: screening, calculations and preferences happen in your browser. Nothing about your screen is stored on a WheelHQ server.

Data and privacy

Market data comes from Alpaca. Your key stays in your browser and goes only to Alpaca. WheelHQ does not place trades. Production analytics are cookieless and never receive your key, tickers or filter values.
