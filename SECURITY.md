# Security policy

WheelHQ is a static, client-side application. The Alpaca API key is stored in the user's
browser and is sent only to `*.alpaca.markets`; the site's host never receives it.

## Reporting a vulnerability

Please report security issues privately through the repository's private
vulnerability-reporting feature rather than opening a public issue. Do not include a live
Alpaca key, account details, or other secrets in a report. If you believe a key was
exposed, rotate it in the Alpaca dashboard immediately.
